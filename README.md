# CoverLetterSite

5년차 웹 개발자의 경력, 물류 포워딩 도메인 경험, ReCheck 사이드 프로젝트를 소개하는 인터랙티브 자기소개서 사이트입니다.

## Tech Stack

- Vue 3
- TypeScript
- Tailwind CSS
- Vite
- Vercel

## Local Development

```bash
pnpm install
pnpm run dev
```

로컬 기본 주소:

```text
http://localhost:5173
```

## Build

```bash
pnpm run build
```

## Content Notes

- 임시 이미지는 `public/test-image.jpg`를 사용합니다.
- 실제 배포 전 `src/App.vue`의 이메일, GitHub, 이력서 PDF 링크를 교체해야 합니다.
- ReCheck Chrome Web Store 링크는 이미 연결되어 있습니다.
